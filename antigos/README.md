# Resultados antigos

Esta pasta guarda rodadas antigas de `outputs/`, `reports/` e pacotes de
relatorio quando o script da AWS inicia uma nova execucao limpa.

O conteudo arquivado aqui nao e versionado pelo Git, porque os arquivos podem
ficar grandes e sao artefatos de execucao. A pasta existe apenas para preservar
historico local na instancia ou na maquina de trabalho.
